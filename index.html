סטודיו לקורס וידאו

סקיל ל-Claude Code שבונה קורס וידאו שלם בעברית: סילבוס, שיעורים מונפשים עם קריין, כתוביות ותמונה ממוזערת, ומדריך מלווה. כל שיעור הוא קובץ טקסט אחד, ותיקון משפט לא דורש לערוך וידאו.

מה מקבלים

  • סילבוס ברמות ובפרקים, שאתה מאשר לפני שנכתב שיעור אחד.
  • שיעורים של 2 עד 4 דקות ב-1920 על 1080: קריינות בקול מלאכותי שנבדקת אוטומטית, וסצנות שעולות בדיוק על המילה הנאמרת. יש כותרות, רשימות, השוואות, תרשימים חיים, איורים, צילומי מסך עם סימון, כרטיסי תרגיל וקוד QR.
  • כתוביות קריוקי צרובות בסרטון, ותמונה ממוזערת לכל שיעור.
  • סילבוס, טקסטים לדף הקורס ומדריך מלווה ב-Word וב-PDF, ודף צפייה בכל הקורס.
  • תיקון אחרי שהסרטון כבר מוכן: מקליטים מחדש רק את הפסקה שהשתנתה.

התקנה

1
פותחים את Claude Code ומדביקים את הבקשה הזאת: 
תתקין לי את הסקיל course-video-studio עם הפקודה הזאת, ואחר כך תבדוק שכל מה שהוא צריך מותקן אצלי (Python, ffmpeg, Node) ותתקין מה שחסר:
curl -fsSL https://hiyabh.github.io/course-video-studio/install.sh | bash
2
יוצרים מפתח Gemini בחינם ב-aistudio.google.com/apikey. הוא משמש לקריינות ולאיורים, שהם החלק היחיד בתהליך שעולה כסף, לפי שימוש. כש-Claude יבקש, נותנים לו את המפתח והוא ישמור אותו בקובץ .env של הקורס.
3
סוגרים ופותחים מחדש את Claude Code, ומבקשים: 
תבנה לי קורס וידאו על ___ עבור ___. תתחיל מסילבוס, ותראה לי אותו לפני שאתה כותב שיעורים.

איך זה עובד

  • קודם סילבוס: Claude שואל כמה שאלות על הלומדים ועל המטרה, ומציג טבלת שיעורים לאישור.
  • שיעור אחד מלוטש: הוא כותב את השיעור הראשון, מקליט, ומרנדר טיוטה מהירה. רק אחרי שאתה מאשר אותה הוא ממשיך לשאר השיעורים.
  • עובדות: כל מחיר, תאריך או שם שנאמר בקורס נבדק ונרשם עם מקור בקובץ עובדות.
  • בקרה: לפני מסירה הוא בודק דפי פריימים, את עוצמת השמע, ותמלול חוזר של הקריינות מול התסריט.

שיעור לדוגמה מגיע עם הסקיל. אחרי ההתקנה אפשר לבקש: "תבנה את שיעור הדוגמה ותראה לי טיוטה".

עדכון לגרסה חדשה

curl -fsSL https://hiyabh.github.io/course-video-studio/install.sh | bash -s -- --update

מה שצריך במחשב: Python 3.10 ומעלה, ffmpeg ו-Node.js 18 ומעלה. Claude Code מתקין אותם בעצמו. בהקראה הראשונה יורד מודל תמלול עברי בנפח של כ-1.6 ג'יגה, פעם אחת בלבד.
